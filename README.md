# La Vintage — biblioteca de figurinhas

Assets do aplicativo La Vintage, servidos por CDN para o app baixar sob demanda.

- `manifesto.json` — catálogo (id, categoria, nome, tamanho, hash)
- `stickers/<categoria>/<arquivo>.webp` — as figurinhas, em WebP sem perda

CDN: `https://cdn.jsdelivr.net/gh/LauroAnd34/la-vintage-assets@v1/`
